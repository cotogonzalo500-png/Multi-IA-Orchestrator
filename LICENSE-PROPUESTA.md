# Licencia: PROPUESTA (no definitiva)

**Esta edición todavía no tiene licencia.** Hasta que el autor apruebe una, los autores se reservan todos los derechos: el código se puede leer, pero no hay permiso explícito para redistribuirlo ni modificarlo.

## Opciones para decidir
| Licencia | Permite | Pide | Comentario |
|---|---|---|---|
| **MIT** (sugerida) | uso, modificación y redistribución, incluso comercial | conservar el aviso de copyright | la más simple y la más común en plugins |
| Apache-2.0 | lo mismo que MIT, más una concesión de patentes | aviso de copyright y de cambios (NOTICE) | más protección legal; el texto es más largo |
| GPL-3.0 | uso y modificación | que las derivadas usen la misma licencia | obliga a mantener abierto el código de las derivadas |

## Componentes de terceros
- La edición no incluye código ni binarios de terceros: Codex, Antigravity, Node.js y Claude Code los instala cada usuario desde su fuente oficial.
- El ícono de la edición personal **no** se incluye porque su origen y sus derechos no están documentados.

Cuando se apruebe la licencia: agregar el archivo `LICENSE`, el campo `license` en `.claude-plugin/plugin.json` y borrar este archivo.
